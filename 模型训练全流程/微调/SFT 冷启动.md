**SFT冷启动**（Cold-Start SFT）是指在大语言模型（LLM）强化学习（RL）训练前，先通过少量高质量的监督微调（Supervised Fine-Tuning, SFT）数据对模型进行初始化训练的策略。
这一阶段旨在解决RL训练中的"冷启动问题"，为后续强化学习提供稳定的起点。

## 1. 核心概念与必要性

1. 冷启动问题的本质

+ 强化学习初期，模型缺乏有效的行为先验，容易陷入低质量输出的探索困境

+ 纯RL训练收敛慢、不稳定，且可能产生不符合人类偏好的输出（如语言混杂、格式混乱）

2. SFT冷启动的作用

+ **行为克隆**：通过模仿高质量人类示范数据，快速建立基础能力

+ **稳定训练**：为RL提供合理的初始策略，加速收敛并提升最终性能

+ **消除缺陷**：修正预训练模型的基础问题（如格式错误、语言混杂）

## 2. 实施方法

典型的冷启动SFT流程包含三个关键步骤：

**1. 数据生成**

+ 利用现有模型或专家系统生成候选响应

+ 重点覆盖目标任务的典型场景和边界案例

**2. 人工后处理**

+ 对生成数据进行质量筛选和修正

+ 确保输出符合目标格式、语言一致性和逻辑正确性

**3. 标准化训练**

+ 使用小规模高质量数据（通常几百至几千条）进行1-3轮SFT

+ 避免过度微调，保留模型的探索能力

## 3. 最佳实践建议

1. **数据质量 > 数据量**：冷启动SFT应聚焦高质量、多样化的示范数据，而非大规模数据；

2. **控制训练轮数**：通常1-3轮SFT足够，过度微调会损害模型后续的RL探索能力；

3. **任务对齐设计**：

   + SFT数据应与最终RL目标一致
  
   + 包含思维链（CoT）等推理过程可提升后续RL效果

4. **渐进式过渡**：SFT后应平滑过渡到RL训练，可采用课程学习策略逐步增加任务难度；

5. **评估指标**：监控冷启动后模型的基础能力（格式正确性、语言一致性）和RL训练的收敛速度
