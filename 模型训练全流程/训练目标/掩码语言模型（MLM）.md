
**MLM（掩码语言建模）** 是双向预训练语言模型的核心训练目标，通过"完形填空"式任务让模型学习上下文表示。

## 1. 核心定义与原理

+ **基本思想**

  随机掩码（mask）输入序列中的一部分 token，训练模型根据**双向上下文**（左右两侧）预测被掩码的原始内容

+ **数学目标**

  最大化被掩码位置的条件概率：

$$L_{MLM}=-\sum_{t \in M}{log P(x_t|x_{\\M};\theta)}$$

其中 $M$ 为被掩码位置集合， $x_{\M}$表示未被掩码的上下文

+ 双向性本质

  与 CLM 的单向依赖不同，MLM 允许每个 token 同时访问左侧和右侧信息，使模型能捕获更丰富的语义关联

## 2. 技术实现细节

### 标准掩码策略（BERT 原始设计）

对每个训练样本执行以下操作：

+ 掩码比例：随机选择 15% 的 token 进行处理

+ 掩码方式分布：

  + 80% 概率替换为 [MASK] token（如 "我 爱 [MASK] 工 智 能"）
 
  + 10% 概率替换为随机 token（如 "我 爱 苹 工 智 能"）
 
  + 10% 概率保持原 token 不变（如 "我 爱 人 工 智 能"）‘’

*设计动机：后两种策略缓解预训练-微调阶段的分布差异——真实场景中极少出现 [MASK] token，避免模型过度依赖特殊标记*
 
###  掩码粒度演进

| 策略 | 描述 | 优势 |
|------|-----|-----|
| Token-level | 随机掩码单个 subword token | 原始 BERT 方案 |
| Whole Word Masking (WWM) | 掩码整个词的所有 subword tokens | 保持语义完整性，避免信息泄露 |
| Span Masking | 连续掩码多个 token（如 3-5 个） | 模拟更自然的缺失模式，提升长距离依赖建模 |

*中文场景特别受益于 WWM：由于中文分词特性，掩码单个字符可能导致语义碎片化，全词掩码更符合语言规律*

### 注意力机制

+ 使用全连接注意力（无因果掩码），每个位置可关注序列中所有其他位置

+ 与 CLM 的对角掩码形成鲜明对比，这是实现双向建模的关键

## 优势与局限

### ✅ 核心优势

**1. 双向上下文理解**：天然适合需要全局语义的任务（如文本分类、命名实体识别、问答）

**2. 训练效率高**：单次前向传播可并行计算所有掩码位置的损失，无需自回归解码

**3, 表示能力强**：实验证明 MLM 预训练的模型在 GLUE 等理解类基准上显著优于单向模型

### ⚠️ 固有局限

1. 预训练-微调不一致：

   + 预训练时输入含 [MASK]，微调时无此标记
  
   + 掩码位置固定（15%），而真实任务需处理任意位置

2. 不适合直接生成：

   + 双向架构无法直接用于自回归文本生成
  
   + 需额外设计（如结合解码器）才能支持生成任务

3. 计算开销：仅 15% 的 token 参与损失计算，训练效率低于 100% 利用的 CLM

4. 掩码率敏感性：研究表明 40% 掩码率在某些场景下优于标准 15%，最优比例依赖模型规模与任务
