**CLM（因果语言建模）** 是大语言模型最主流的预训练目标之一，其核心思想是自回归地预测序列中的下一个词元（token），仅基于该位置之前的历史上下文。

## 1. 核心定义与原理

+ **基本概念**

  CLM 是一种自回归（autoregressive）语言建模方法，模型在训练时学习预测序列中第 $t$个 token，条件是前 $t-1$个tokens。

+ **因果含义**

  名称中的"因果"并非指因果推理，而是强调**时间/序列上的单向依赖关系**——每个位置只能"看到"过去的信息，不能访问未来 token，符合语言生成的自然时序特性

+ **数学目标**

  最大化整个序列的对数似然概率：

$$L_{CLM}=-\sum_{t=1}^{T}{log P(x_t|x_{<t}\;\theta)}$$

其中 $\theta$为模型参数， $T$ 为序列长度

## 2. 关键技术与实现

### 1. 注意力掩码机制

+ CLM 使用**对角掩码矩阵（causal mask）**，在 Transformer 的自注意力层中屏蔽未来位置的信息 ;

+ 具体实现：注意力权重矩阵的上三角部分（包括对角线以上）被设为 −∞，经 softmax 后对应位置权重为 0，确保每个 token 仅能关注左侧上下文

## 4. 优势与局限

### ✅ 优势

1. 生成能力强：训练目标与文本生成任务完全一致，无需调整架构即可直接生成连贯文本

2. 训练简单高效：无需构造特殊输入（如 MLM 的 [MASK] 标记），直接使用原始文本

3. 可扩展性好：GPT-3 证明 CLM 在超大规模参数和数据下仍能持续提升性能 

4. 支持长文本生成：通过滑动窗口等技术可处理超长序列

### ⚠️ 局限

1. 单向上下文：无法利用右侧信息，在需要全局理解的任务（如完形填空）上弱于双向模型

2. 误差累积：自回归生成时，早期预测错误会传播影响后续输出

3. 训练-推理不一致：训练时使用真实历史 token（teacher forcing），推理时使用模型自身预测，存在暴露偏差（exposure bias）

## 5. 典型应用场景

+ 文本续写与创作：故事生成、诗歌创作、代码补全

+ 对话系统：聊天机器人、虚拟助手（将对话历史作为前缀）

+ 指令微调基础：SFT（Supervised Fine-Tuning）通常在 CLM 预训练模型上进行

+ 思维链推理：通过 prompt 引导模型逐步输出推理过程

## 6. 发展趋势

+ 混合训练目标：部分新模型尝试结合 CLM 与 MLM 优势（如 Encoder-Decoder 架构）

+ 长上下文优化：通过 RoPE 扩展、滑动窗口注意力等技术突破上下文长度限制

+ 推理加速：Speculative Decoding、Lookahead Decoding 等技术缓解自回归生成速度瓶颈
