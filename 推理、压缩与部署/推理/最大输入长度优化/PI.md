Position Interpolation (PI) 是 2023 年由 Meta 团队提出的一种无需重新预训练即可扩展 RoPE 模型上下文长度的技术 。
其核心思想是将**长序列的位置索引“压缩”回训练时见过的范围**，用内插（interpolation）替代外推（extrapolation），从而规避 RoPE 的外推失效问题。

## PI 核心思想：内插代替外推

PI 的核心操作：将长序列的位置索引线性缩放至训练窗口内。

### 数学定义

设目标扩展长度为 $L_{target}$，缩放因子：

$$s=\frac{L_{target}}{L_{train}} (s > 1)$$

对输入序列中位置 $m \in [0, L_{target})$，PI 将其映射为：

$$m'=\frac{m}{s} \in [0, L_{train}]$$

即：用训练时见过的 $m'$ 位置编码，替代未知的 $m$ 位置

### 直观理解

+ 原始训练：2048 个位置 → 2048 个“刻度”
+ 直接外推：32768 个位置 → 需要 32768 个新刻度（模型没见过）
+ PI 内插：32768 个位置 → 压缩到 2048 个刻度内，每个刻度代表 16 个原始位置
  + 位置 0 → 刻度 0.0
  + 位置 16 → 刻度 1.0
  + 位置 32767 → 刻度 2047.9
