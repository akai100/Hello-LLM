
大语言模型在推理阶段的最大输入长度限制，本质上源于训练阶段已固化的架构设计、位置编码机制和数据分布，这些限制在推理时无法动态突破。

## 位置编码的外推失效（根本原因）

### 绝对位置编码

+ 使用可学习的Position Embedding表，维度固定（如512个位置）

+ 推理时输入超过512 → 位置索引越界，无对应embedding → 模型无法理解位置信息

### 旋转位置编码

+ 通过旋转矩阵编码相对位置：

+ 训练时仅见过 $m \in [0, L_{train}$（如 $L_{train}=2048$）

+ 推理时 $m >= L_{train}$ -> 高维度 $\theta$ 过大 -> 旋转角度超出训练分布 -> 位置关系失真

  + 例如：2048位置后，cos(2048θ) 可能剧烈震荡，破坏注意力权重

## 注意力机制的计算瓶颈

### 时间与复杂度

+ 128K序列的KV Cache可能超过单卡显存（如A100 80GB），导致OOM
+ 注意力矩阵计算时间从毫秒级升至秒级，无法满足实时推理

### 数值稳定性问题

+ 长序列softmax分母过大 → 梯度消失
+ 累积浮点误差在长距离传播中放大 → 注意力权重失真
