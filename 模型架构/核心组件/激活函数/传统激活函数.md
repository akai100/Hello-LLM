## Sidmoid

数学公式：

$$\frac{1}{1+e^{-x}}$$

+ 优点
  + 输出可解释为概率（适合二分类）
  + 全局可导
+ 缺点：
  + 梯度消失
  + 非零中心

## ReLu 及其变体

### ReLU

**数学公式**

$$max(0,x)$$

+ 优点
  + 计算极简
  + 缓解梯度消失
  + 稀疏性：约 50% 神经元失活 -> 降低过拟合
+ 缺陷
  + 神经元死亡：负输出导致永久失活
  + 非零中心：输出均值偏移

### Leaky ReLU

$$
\begin{equation}
\begin{cases} 
x, & x > 0 \\
\alpha x, &  x <= 0
\end{cases}
\end{equation}
$$

+ 优点
  + 缓解神经元死亡

### ELU

$$
\begin{equation}
\begin{cases}
x & x > 0 \\
\alpha(e^x - 1) & x <= 0
\end{cases}
\end{equation}
$$

+ 优点
  + 平滑区间，均值近零
