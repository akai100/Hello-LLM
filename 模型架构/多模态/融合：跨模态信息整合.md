**目标**：将对齐后的多模态特征进行深度交互，生成统一表征用于推理/生成。

## 1. 融合架构分类

| 架构类型 | 信息流 | 交互深度 | 计算效率 | 代表模型 |
|----------|-------|---------|---------|-------------|
| 早期融合 | 原始数据拼接 → 统一编码 | 浅 | 高 | VideoBERT（视频+音频） |
| 双塔融合 | 独立编码 → 相似度计算 | 无交互 | 极高 | CLIP、SigLIP |
| 晚期融合 | 独立推理 → 结果融合 | 无交互 |高 | 多模态 Ensemble |
| 中期融合 | 独立编码 → 特征交互 → 联合推理 | 深 | 中 | LLaVA、Qwen-VL |
| 层次融合 | 多粒度特征分层交互 | 极深 | 低 | OFA、KOSMOS-2 |

## 2. 融合技术详解

### 2.1 特征拼接

+ 方法： $h_fused=[h_{vis};h_{text}]$
+ 适用：简单任务（如二分类）
+ 局限：缺乏模态间交互

### 2.2 元素级操作

+ 加法：$h = h_{vis} + h_{text}$
+ 乘法（Hadamard）: $h=h_{vis}\odot h_{text}$
+ 适用：特征维度对齐后的轻量融合

### 2.3 注意力融合 ⭐ 主流方案

| 类型 | Query | Key/Value | 特点 |
|------|-------|-----------|------|
| Self-Attention | 融合后序列 | 同序列 | 建模模态内+模态间关系 |
| Cross-Attention | 文本 | 图像 | 文本引导视觉聚焦 |
| Co-Attention | 双向交互 | 双向 | 深度交互，计算昂贵 |
| Gated Cross-Attention (Flamingo) | 文本 | 图像 | 门控机制控制信息流 |

### 2.4 Q-Former / Perceiver（特征压缩融合）

+ 动机：原始视觉 token 数量大（196+），直接输入 LLM 计算昂贵
+ Q-Former 流程：
1. 可学习 query 向量 $q_1,...,q_k (k << N)$
2. Query 与视觉特征做 cross-attention
3. 输出压缩后的 k 个 token（如 k=32）

+ 优势：
  + 降低 LLM 输入长度 6× 以上
  + 可学习聚焦关键区域（如文字、人脸）
+ 应用：BLIP-2、InstructBLIP

### 2.5 MoE 融合器（前沿探索）

+ 原理： 不同专家网络处理不同模态组合

$$h_{fused}=\sum_{i=1}^{E}{G_i(x)\cdot Expert_i(x)}$$

其中 $G_i$为门控网络，决定专家权重

+ 优势：提升模型容量而不显著增加计算量
+ 挑战：专家负载均衡、训练稳定性
+ 应用：Google 的 Unified-MoE（统一多模态 MoE）

## 3. 融合中的关键挑战与解决方案

| 挑战 | 原因 | 解决方案 |
|-----|----|-----|
| 模态不平衡 | 视觉 token 数 >> 文本 token | Q-Former 压缩、自适应 token 选择 |
| 位置信息丢失 | 视觉 token 打平为 1D 序列 | MRoPE（Qwen）、2D-RoPE（CogVLM） |
| 长序列计算 | 视频/文档导致序列过长 | 稀疏注意力、KV Cache 复用（Qwen3-VL 256K） |
| 模态冲突 | 模态间信息矛盾（如图说“晴天”但图像阴天） | 置信度加权融合、不确定性建模 |
