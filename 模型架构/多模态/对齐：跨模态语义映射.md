**目标**：建立不同模态特征间的语义对应关系，使“狗”的图像特征与文本特征在共享空间中距离相近。

## 1. 对齐粒度分类

| 粒度 | 说明 | 技术方案 | 应用场景 |
|------|-----|---------|------------|
| 全局对齐 | 整图 ↔ 整句 | 对比学习（CLIP） | 图文检索、零样本分类 |
| 细粒度对齐 | 区域 ↔ 短语 | 跨模态注意力、Grounding | 视觉问答、指代表达 |
| 实例级对齐 | 物体 ↔ 实体 | 检测框 + 文本嵌入 | 开放词汇检测（OWL-ViT） |
| 时序对齐 | 视频片段 ↔ 句子 | 时序对比学习 | 视频字幕生成 |

## 2. 对齐技术方法论

### 2.1 对比学习（Contrastive Learning）⭐ 主流方案

+ 原理：拉近正样本对距离，推远负样本对
+ 损失函数
  + InfoNCE (CLIP)：
$$L_{InfoNCE}=-log\frac{e^{sim(v_i, t_i)/τ}}{\sum_{j=1}^{N}{e^{sim(v_i, t_j)/τ}}}$$
  + Sigmoid Loss(SigLIP)

$$L_{sigmoid}=-log\sigma(s_{ii}/τ)-\sum_{j!=i}{log\sigma(-S_{ij}/τ)}$$

+ 关键设计：
  + 温度系数 τ：控制分布锐度（通常 0.01–0.1）
  + Hard Negative Mining：主动挖掘困难负样本提升效果
  + Multi-view Augmentation：同一图像不同裁剪视为正样本

### 2.2 掩码语言建模（Masked Language Modeling, MLM）

+ 原理：给定图像，预测被掩码的文本词
+ 代表模型：VL-BERT、UNITER
+ 优势：强制模型理解图像与文本的细粒度关联
+ 局限：训练效率低于对比学习

### 2.3 图像-文本匹配（Image-Text Matching, ITM）

+ 原理：二分类任务，判断图文对是否匹配
+ 实现：[CLS] token + 二分类头
+ 应用：ALBEF、BLIP 的预训练目标之一

### 2.4 跨模态注意力

+ 原理：文本 query 与图像 key/value 计算注意力

$$CrossAttn(Q_{text}, K_{vis}, V_{vis})=softmax(\frac{Q_{test}K_{vis}^T}{\sqrt{d}})V_{vis}$$

+ 优势：实现细粒度对齐

+ 应用：Flamingo 的 Gated Cross-Attention、Qwen-VL 的视觉 token 插入

## 3. 对齐质量评估指标

| 指标 | 计算方式 | 说明 |
|------|---------|-------|
| Recall@K | 检索 top-K 中是否包含正样本 | 图文检索标准指标 |
| Zero-shot Accuracy | 零样本分类准确率 | 衡量开放词汇能力 |
| Alignment Score | 余弦相似度均值 | 直观但可能过拟合 |
| TIFA (Text-to-Image Faithfulness) | 生成图像与文本一致性 | 评估生成任务对齐质量 |
