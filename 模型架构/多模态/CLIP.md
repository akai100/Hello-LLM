CLIP（Contrastive Language–Image Pre-training）是由 OpenAI 于 2021 年提出的开创性多模态预训练模型 ，首次证明通过大规模对比学习可实现强大的跨模态对齐，
无需下游任务微调即可在多种视觉任务上实现零样本迁移（Zero-shot Transfer）。它奠定了现代视觉语言模型（VLM）的技术基础。

## 核心思想：从“分类”到“检索”的范式转变

**传统计算机视觉范式**

```
图像 → 特征提取 → 全连接层（固定类别）→ 分类（如 ImageNet 1000 类）
```

**CLIP 范式：图文对比学习**

```
图像 ↔ 文本描述 → 共享语义空间 → 相似度匹配
```

+ **核心洞见**：将图像分类转化为**图像-文本检索问题**
  + 给定图像，从候选文本描述中检索最匹配的描述
  + 给定文本，从候选图像中检索最匹配的图像

## 训练方法：大规模对比学习

### 1. 预训练数据

+ 数据集：WIT（WebImageText），从互联网爬取的 4 亿（400M）高质量图文对
+ 数据清洗
  + 基于文本-图像相似度过滤低质量对
  + 去重、去敏感内容
+ 多样性： 覆盖自然图像、图表、艺术、截图等多种类型

### 2. 对比学习目标

给定 batch 内 $N$个图像-文本对 $(I_i, T_i)$

1. 编码所有图像和文本

$$v_i=f_{vision}(I_i), t_j=f_{text}(T_j)$$

2. 计算相似度矩阵（余弦相似度）：

$$S_{ij}=\frac{v_i \cdot t_j)}{||v_i||||t_j||} \cdot \frac{1}{τ}$$

其中 τ为温度系数（通常 0.07）

3. 对称对比损失

$$L = -\frac{1}{N}\sum_{i=1}^{N}{[log \frac{e^{S_{ii}}}{\sum_{j=1}^{N}{e^{S_{ij}}}} + log\frac{e^{S_{ii}}}{\sum_{j=1}^{N}{e^{S_{ji}}}}]}$$
