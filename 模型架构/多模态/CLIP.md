CLIP（Contrastive Language–Image Pre-training）是由 OpenAI 于 2021 年提出的开创性多模态预训练模型 ，首次证明通过大规模对比学习可实现强大的跨模态对齐，
无需下游任务微调即可在多种视觉任务上实现零样本迁移（Zero-shot Transfer）。它奠定了现代视觉语言模型（VLM）的技术基础。

## 核心思想：从“分类”到“检索”的范式转变

**传统计算机视觉范式**

```
图像 → 特征提取 → 全连接层（固定类别）→ 分类（如 ImageNet 1000 类）
```

**CLIP 范式：图文对比学习**

```
图像 ↔ 文本描述 → 共享语义空间 → 相似度匹配
```

+ **核心洞见**：将图像分类转化为**图像-文本检索问题**
  + 给定图像，从候选文本描述中检索最匹配的描述
  + 给定文本，从候选图像中检索最匹配的图像

 ## 架构设计：双塔结构

CLIP 采用简洁高效的双编码器架构：

```
┌─────────────────┐          ┌─────────────────┐
│  图像编码器      │          │  文本编码器      │
│  (Image Encoder)│          │  (Text Encoder) │
├─────────────────┤          ├─────────────────┤
│ • ResNet-50/101 │          │ • Transformer   │
│ • ViT-B/32      │          │ • BPE tokenizer │
│ • ViT-B/16      │          │ • 49K 词表      │
│ • ViT-L/14      │          │ • 最大 77 tokens│
└────────┬────────┘          └────────┬────────┘
         │                            │
         └───────────┬────────────────┘
                     ▼
          ┌──────────────────────┐
          │  投影层 (Projection)  │
          │  Linear(D_in → 1024) │
          └───────────┬──────────┘
                      ▼
          ┌──────────────────────┐
          │  对比学习损失函数     │
          │  (InfoNCE / Softmax) │
          └──────────────────────┘
```

## 训练方法：大规模对比学习

### 1. 预训练数据

+ 数据集：WIT（WebImageText），从互联网爬取的 4 亿（400M）高质量图文对
+ 数据清洗
  + 基于文本-图像相似度过滤低质量对
  + 去重、去敏感内容
+ 多样性： 覆盖自然图像、图表、艺术、截图等多种类型

### 2. 对比学习目标

给定 batch 内 $N$个图像-文本对 $(I_i, T_i)$

1. 编码所有图像和文本

$$v_i=f_{vision}(I_i), t_j=f_{text}(T_j)$$

2. 计算相似度矩阵（余弦相似度）：

$$S_{ij}=\frac{v_i \cdot t_j)}{||v_i||||t_j||} \cdot \frac{1}{τ}$$

其中 τ为温度系数（通常 0.07）

3. 对称对比损失

$$L = -\frac{1}{N}\sum_{i=1}^{N}{[log \frac{e^{S_{ii}}}{\sum_{j=1}^{N}{e^{S_{ij}}}} + log\frac{e^{S_{ii}}}{\sum_{j=1}^{N}{e^{S_{ji}}}}]}$$

## 优势与局限性

### ✅ 核心优势

| 优势 | 说明 |
|------|------|
| 开放词汇识别 | 无需重新训练即可识别新类别（如“柯基犬”） |
| 分布外鲁棒性 | 对未知类别/分布偏移表现优于监督模型 |
| 多模态统一表征 | 图像与文本共享语义空间，支持跨模态检索 |
| 可解释性 | 通过文本提示（prompt engineering）控制模型行为 |

### ❌ 关键局限

| 局限 | 原因 | 后续改进方向 |
|------|-----|---------------|
|细粒度理解弱 | 全局特征对齐，缺乏区域-短语对齐 | 引入 grounding（如 BLIP、GLIP）
| 文本生成能力缺失 | 仅支持编码，无法生成文本 | 与 LLM 结合（如 LLaVA、Qwen-VL）
| Batch Size 依赖强 | 小 batch 下性能显著下降 | 改进损失函数（如 SigLIP 的 Sigmoid Loss）
| 长尾分布问题 | 对罕见概念识别能力弱 | 扩展训练数据 + 合成数据增强 |
| 计算成本高 | 需超大 batch 与海量数据 | 蒸馏（DeiT）、自监督预训练（MAE） |
