## 设计动机

图像的 patch 是有明确空间位置的（比如左上角的 patch 和右下角的 patch 语义完全不同），如果不给 patch 标注位置信息，模型根本无法区分 “哪个 patch 在哪个位置”，自然无法学习到图像的空间结构。
位置编码的唯一目的，就是给每个 patch token 赋予**唯一的空间位置信息**。

## 实现方式

ViT 没有沿用 NLP 中经典的 “正弦位置编码”，而是选择了**可学习的 1D 位置嵌入**，原因是：

+ 图像 patch 的序列是 2D 空间展开的 1D 序列，可学习的方式更灵活，能自适应图像任务；

+ 实现简单，且在大规模数据下效果更好。

实现逻辑：

1. 假设输入图像被分成N个 patch（比如 224×224 图像，16×16 patch，N=196），加上 [CLS] token 后，总序列长度是N+1；

2. 初始化一个可学习的位置嵌入矩阵pos_embedding，形状为(N+1, D)（D 是隐藏维度，比如 768）；

3. 将这个位置嵌入矩阵与 “[CLS] token + patch embeddings” 的拼接结果逐元素相加，完成位置信息的注入。

## 关键特点与变体

+ **原始 ViT 的 1D 限制**：1D 位置嵌入只是给每个位置分配一个唯一向量，没有显式编码 “行 / 列” 的 2D 空间关系，但实际效果已足够好；

+ **微调时的插值处理**：如果预训练用 224×224（196 个 patch），微调用 384×384（576 个 patch），需要对预训练的位置嵌入做插值（比如双线性插值），适配新的序列长度；
  
+ **改进变体**：后续有工作提出 2D 位置嵌入（分别编码行和列的位置，再拼接），能更精准捕捉空间关系，但提升幅度有限。
