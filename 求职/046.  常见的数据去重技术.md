**重复数据的危害包括：**

+ 模型对重复样本过拟合；

+ 训练效率降低（重复计算）；

+ 评估指标失真（验证/测试集中若含训练样本，会高估性能）

**常用的数据去重技术：**

+ 精确匹配去重：对完全相同的样本（如文本、图像哈希值）进行删除

+ 近似去重（Near-duplicate detection）：

  + 使用 MinHash + LSH（局部敏感哈希） 检测相似文本
 
  + 使用 SimHash 或 Sentence Embeddings + 距离度量（如余弦相似度） 判断语义重复
 
  + 对图像可使用 感知哈希（pHash） 或 特征嵌入相似度。

+ 基于嵌入的聚类去重：将样本映射到向量空间后聚类，每簇保留一个代表样本
