现象

微调完成，loss 正常

上线推理：

并发一上来就 OOM

显存使用比 base model 高很多

根因分析
1️⃣ LoRA + 长上下文 = KV Cache 爆炸

微调数据：

max_seq_len = 4096

大量长样本

结果：

模型学会生成更长回答

平均输出 token 数 ↑↑

👉 推理时 KV Cache 使用量飙升

2️⃣ 推理参数没限制

max_new_tokens = 2048

没有 early stop

没有 repetition penalty

定位方式

对比：

SFT 前后：

平均 prompt 长度

平均生成长度

监控：

KV Cache 占用

TPS 突降点

解决方案
✅ 推理侧

限制：

max_new_tokens = 512


加 stop words

设置 repetition penalty

✅ 训练侧

混入 “短答样本”

显式教模型 “何时停止”

可复用经验

微调会改变“生成长度分布”，而推理系统最怕的就是长度失控
